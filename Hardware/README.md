# Hardware design files

This directory contains the editable electronics design sources used by the ENIGMA prototype.

## Contents

- `KiCad/Enigma_Main`: main controller board
- `KiCad/Enigma_Keyboard`: keyboard board
- `KiCad/Enigma_LEDs`: lampboard LED board
- `KiCad/Enigma_Hall`: Hall-sensor board
- `KiCad/Libraries`: project-specific symbols, worksheet, and image assets
- `io-assignment.drawio`: editable I/O assignment diagram

Generated caches, local settings, autosaves, and backup archives are intentionally excluded from version control. PDF reference schematics are available under [`docs/schematics`](../docs/schematics).
